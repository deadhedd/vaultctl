## Summary

The change extends client sync to track direct submodules, preserve pinned checkout behavior, recover child conflicts, and record successful child gitlinks as a group. The phase ordering and grouped index checks are careful, but the URL guard rejects a common Git SSH remote form, and nested checkout validation applies direct tracking metadata rules to repositories that should use native Git behavior.

## Blockers

### 🔴 SCP-style SSH remotes prevent child commits and pushes, `internal/vaultctl/submodule_sync.go:908`
**Problem**: `canonicalGitEndpoint` calls `url.Parse` before `looksLikeSCPLikeURL`. Go rejects a standard Git remote such as `git@host:org/project.git` as a URL with a colon in its first path segment, so the function returns an error before recognizing Git's SCP syntax. `checkSubmodulePushEndpoints` runs on every tracking child autosave commit and push, even when no projection source is configured.
**Why it matters**: A tracking child using a common SSH `origin` can fetch successfully but then cannot commit safe local work or push ahead or reconciled commits. This breaks AC-5 and AC-6 for a normal Git remote and leaves the parent link phase incomplete.
**Suggested fix**: Recognize and retain valid SCP-style Git URLs before applying `net/url` parsing, while keeping local path canonicalization and malformed endpoint refusal. Cover a tracking child with an SCP-style `origin` in the endpoint guard tests.

## Major

### 🟠 Native nested submodule branch metadata is rejected, `internal/vaultctl/submodule_sync.go:1196`
**Problem**: Recursive checkout preflight calls `loadDirectSubmodules` on each initialized child. That loader enforces direct tracking rules, including rejecting `branch = .` at line 468, on the child's nested `.gitmodules` entries. Git permits `branch = .` for submodules, and the final nested operation is a recorded commit checkout that does not need branch selection.
**Why it matters**: A valid nested submodule causes an otherwise successful sync to fail before final recursive checkout. AC-12 says nested submodules retain native Git recorded revision behavior; direct tracking metadata restrictions should not change that behavior.
**Suggested fix**: Use a path and gitlink validation path for nested recursive checkout preflight that does not apply direct tracking branch or pin policy. Add a nested `branch = .` case that reaches the recorded commit.
